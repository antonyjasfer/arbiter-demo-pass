# TaskBoard (Arbiter demo)

A tiny task list used as a demo deliverable for [Arbiter](https://github.com/antonyjasfer/arbiter-runner): add a task, tick it done, and a `/health` endpoint.

- `npm start` serves it on `$PORT` (default 3000).
- `npm test` runs the unit tests (Node's built-in test runner).
- `GET /health` returns `{"ok":true}`.

No dependencies. Deployed on Render Free.
